# Email Verification Requirements

1. When a user signs up, they should receive an email with a verification link
2. The user should be able to click the verification link to verify their email address
3. The user should not be able to log in until their email is verified
4. The user should be able to request a new verification email if they don't receive the first one
5. The verification link should expire after a certain amount of time
6. The verification link should be unique to each user
7. The user should be required to verify their email on both web and mobile versions
